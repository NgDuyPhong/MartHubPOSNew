# Docs

## Prefix documentation filenames with creation time
Đặt tên mọi tài liệu mới theo mẫu `YYYY-MM-DD-HHmmss-TEN-TAI-LIEU.md` để thứ tự tên phản ánh thứ tự tạo. Giữ nguyên timestamp ban đầu khi cập nhật hoặc đổi tên nội dung; `docs/README.md` được miễn vì là file chỉ mục cố định.
